AI writing and research

OpenRouter creates the personalized hook. OpenAlex adds author-matched scholarly works and abstracts; LangSearch adds broader web evidence. Both research sources are optional and feed their results into the OpenRouter prompt.

This setting controls LangSearch only. OpenAlex has its own switch and works without a key.

Recommended when configured: OpenAlex results are passed to OpenRouter with LangSearch results, when LangSearch is also enabled.

Create an OpenAlex account and manage the free API key at openalex.org/settings/api. OpenAlex is off by default until a key is saved.

Email sender

SMTP sends the emails. For Gmail, use an App Password—not your normal Google password. The app does not send anything until you switch off dry-run mode.

Pacing and safety

These controls preserve the mailer's existing send gates. A dashboard run may set its daily cap with the slider; this value is the default cap.

What the mailer reads and creates

Your selected list and the six prompt files are inputs. The remaining files are generated locally as you use the tool.

prompts/ contains system.txt, user.txt, no_web.txt, search_query.txt, email_body.txt, and email_signature.txt. All six are needed; the default folder is included with the project.

hooks.json stores generated drafts keyed by professor email. Review it before live sending; set "approved": true to force-send a held hook or "approved": false to reject it.

state.json records completed sends and daily counts so the tool can resume after interruption. sent_log.csv records successful live sends. outbox/ contains email drafts from safe mode.

These files and all uploaded source documents stay in this project folder. The API keys and sender credentials are stored in .env, which is Git-ignored.
